# Sourcing log, group 4 (8 Nov 2026): thin-sourcing chapters

Method: WebSearch and WebFetch only. Direct catalogue APIs (curl to Open Library) were blocked by the proxy, and relbib.de, JSTOR, Crossref and several publisher pages returned browser checks or were off the allowlist. Each addition below was confirmed (author, title, publisher, year) on a catalogue, publisher or bookseller page fetched in this session; the page is linked in the reference where it is public. I did not read the books, so no chapter claim was newly confirmed from their text. No prose changed. Page numbers were added only where a record showed them (Palmer 97–122; Babb 116–124). Reference numbering checked contiguous in all nine files. Style check: 0 errors.

No chapter's reference list carries header notes on gaps, so gaps are logged here only.
